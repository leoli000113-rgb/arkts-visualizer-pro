# ArkTS 可视化编辑器 Pro

基于 [ArkTS-UI-Visualizer](https://github.com/) 改造扩展的 ArkTS/HarmonyOS 可视化 UI 编辑器。

## 功能

- 导入 `.ets` 文件 → 可视化预览 → 拖拽编辑 → 导出代码
- **导入整个 ArkTS 工程目录**：递归读取全部 `.ets` 页面/组件、媒体资源、`resources element` 颜色/字符串 json
- **跨页面**：页面列表切换；「交互预览」模式下点击带 `router.pushUrl/back` 的组件即模拟真机导航（含 `this.open()` 间接调用解析），◀ 返回按导航栈回退
- **跨文件组件渲染**：`import { PageView } from '../components/PageView'` 解析进组件表，按真实内容渲染而非占位卡
- **图片/视频真实渲染**：导入媒体后 `$r('app.media.x')` / `$rawfile` / 相对路径引用解析为真图/可播放视频；`$r` 颜色/字符串资源同样落地
- **自适应屏幕**：画布缩放常开「适应窗口」模式（窗口/设备变化自动重算），手动 −/+ 即退出
- **系统栏安全区**：画布默认显示手机状态栏（时间/信号/电池）与底部手势导航条，应用区与真机非沉浸布局一致；顶栏「系统栏」可开关
- **定位与真机一致**：`.position()` 相对父组件定位（塌缩容器的定位子节点自动上溯到有大小的祖先），负值/百分比参数照常生效，画布布局不随点选组件而变化
- **Stack 与滚动容器尺寸同真机**：Stack 尺寸 = 最大子节点（grid 层叠不塌缩）；Scroll/List/Grid/Tabs 不写宽度也默认占满交叉轴
- 支持 30+ ArkUI 组件（Text/Button/Image/Row/Column/Stack/Grid/List/Tabs/TextInput/Toggle/Slider/Badge/Rating/Divider/Blank 等）
- 三大面板：基础组件 / 复合组件库 / 页面模板（模板带即时缩图预览）
- 28 个页面模板，分 7 大类（基础/首页/列表/表单/网格/个人中心/卡片）
- 22 个复合组件，分 6 类（导航/列表/卡片/表单/反馈/媒体）
- **大纲树独立固定条**：全高一条紧贴导航面板右侧，宽度可拖拽持久化，首部 « 一键收合/展开（默认展开），组件面板拖入路径最短；导航/属性/代码面板可停靠左/右/底三边（首部右键切换），布局持久化
- **大纲树编辑中枢**：行悬停 ＋插入（带约束过滤的选择器）/ ⧉副本 / ✕删除，拖拽移动自动深入 Scroll 等独子容器内层
- **画布「位置调整」模式**：右键组件 → 调整位置，此后拖拽只改偏移不动结构（方向键微调，Esc 退出），告别误触改结构
- **粘贴模式**：复制/剪切后点击容器即放入其内部、点击组件即放到其后，可连续多处（Esc 退出）
- **大纲树拖入更简单**：行中部 60% 直接进容器，拖拽悬停收合容器自动展开，新插入节点自动展开祖先可见
- **画布落点更聪明**：拖入容器按指针位置就近插入（含 Scroll 留白处），边缘窄带才落为兄弟节点
- 设备适配（Mate 80 Pro Max / Mate X7 折叠屏 / Pura X Max 翻盖屏）
- 撤销重做 / 节点剪贴簿（Ctrl+C/X/V/D）/ 属性面板 / 右键菜单
- 侧栏四页签（页面/组件/组件库/模板）+ 搜索 / 拖拽跟手标签 / Stack 对齐吸附参考线
- CodeMirror 6 代码窗（语法高亮/行号/错误行内标记），防抖解析、报错不闪白
- 组件注册表架构（registry）：新增组件只需一份声明，面板/约束/属性区/摘要自动派生
- 纯前端，无后端，localStorage 持久化（项目文件与媒体资源均落盘，配额满自动降级）

## 快速开始

```bash
cd app
npm install
npm run dev
```

浏览器打开 http://localhost:5173

或双击项目根目录 `start.bat` 一键启动。

## 技术栈

React 18 + Vite + TypeScript + Zustand + CodeMirror 6（测试 vitest， lint ESLint flat config）

## 项目结构

```
app/src/
├── parser/       .ets → IR 解析器
├── ir/           IR 数据模型 / 序列化 / 校验（defaults/constraints 为 registry 转接层）
├── registry/     ★ 组件注册表：组件声明（分类/约束/默认节点/属性 schema/摘要）
├── project/      ★ 项目级逻辑：import 提取/路径解析/路由解析/媒体与资源分类/解析缓存
├── renderer/     IR → React DOM 渲染器
├── editor/       拖拽（含吸附参考线）/ 大纲树（插入选择器/行内操作）/ 属性面板 / 右键菜单
├── panels/       顶栏 / 导航面板 / 停靠布局(dock) / 缩放条 / CodeMirror 代码窗 / 帮助弹窗 / 模板缩图
├── templates/    28 个页面模板（7 大类）
├── library/      22 个复合组件（6 大类）
├── devices/      设备档案
└── store/        Zustand 状态管理
```
